Stata Environment, Opening Data and Importing

The Stata interface, reading commands, help, the working folder and do files, followed by opening a dataset, variable types, labels, missing values and importing Excel and CSV files.

120 minutesLab based exerciseStata 15 or later

Learning objectives

By the end of this session, participants will be able to:

  • Identify the main windows of Stata and state the purpose of each.
  • Read a Stata command and recognise common error messages.
  • Use the help system, set the working folder and run a do file.
  • Open the BDHS dataset and inspect it with basic commands.
  • Distinguish numeric and string variables, and use labels and missing values correctly.
  • Import Excel and CSV files and save the data in Stata format.
Introduction

What Stata is

Stata is a statistical package for data management, analysis, graphics and reporting. It is used widely in public health, economics and the social sciences.

  • Work is command driven. Menus exist, but every action corresponds to a typed command that can be saved and repeated exactly.
  • Stata holds one dataset in memory at a time, and every command acts on that dataset.
  • Stata is available in editions (BE, SE and MP) that differ mainly in data size and speed. The commands taught here work in all of them.
Introduction

Working conventions for this course

  • All commands in this course run in Stata 15 and later.
  • Commands and variable names are case sensitive. The command summarize exists, but Summarize does not.
  • Code appears in light panels. Each panel has a Copy button, and the text may be pasted into the Do file Editor.
  • Menu names and window titles can differ slightly between versions. The typed commands do not.
Introduction

The dataset: Bangladesh Demographic and Health Survey 2022

This course uses the women's individual recode file of the 2022 Bangladesh Demographic and Health Survey (BDHS). It holds the interview records of women of reproductive age, aged 15 to 49, with one row for each woman.

  • File name: BDIR81FL.DTA, in Stata format.
  • The file contains 30,078 women and 5,425 variables. Variable names follow the DHS coding scheme, such as v012 for age. This is more than the default limit of 5,000 variables, so the limit must be raised before the file is opened.

Access. Download the dataset from the shared course folder, using the dataset button on the course home page, and save it in your working folder. Use the data for this course only, and cite the source as The DHS Program, BDHS 2022.

Introduction

Windows that open on request

  • Do file Editor: where scripts of commands are written and run.
  • Data Browser (browse): displays the data without allowing changes.
  • Data Editor (edit): displays the data and allows changes.
  • Viewer: shows help pages.
  • Graph window: shows charts produced by graph commands.

Browse before you edit. A stray keystroke in the Data Editor can alter a value. Use the Data Browser unless editing is intended.

Introduction

Entering data in the Data Editor

Small tables can be typed directly into the Data Editor, without writing any command.

  • Open the Data Editor from the toolbar.
  • Click the first cell and type a value. Use Tab to move across and Enter to move down.
  • Stata names the columns var1, var2 and so on. Select a variable and change its name and label in the Properties window.
  • A column that holds only numbers becomes a numeric variable. A column that holds text becomes a string variable.

Typing suits very small tables. Larger data should be imported from a file, which is covered later in this session.

Syntax and help

The general form of a command

Most Stata commands follow one pattern. Everything after the command name is optional.

commandwhat to do
varlistwhich variables
ifwhich observations, by condition
inwhich observations, by position
, optionshow to do it
Syntax and help

Reading a command

summarize v012 v201 if v025 == 2, detail

This asks Stata to summarise the variables v012 (age) and v201 (children ever born), only for observations where v025 equals 2, with detailed statistics.

  • A double equals sign tests a condition. A single sign assigns a value.
  • The comma separates the options from the rest of the command.
  • The code for rural is shown for illustration. Confirm the codes of a variable with codebook v025 before relying on them.
Syntax and help

Useful rules

  • Commands and variable names are case sensitive, and are normally written in lower case.
  • Many commands have abbreviations, for example sum for summarize. This course writes commands in full for clarity.
  • A prefix repeats a command for each group, for example bysort v025: summarize v012.
  • If a command is wrong, Stata prints a message in red together with a return code such as r(199). Nothing is changed in the data.

Syntax and help

Getting help

* Open the help page of a command
help summarize

* Search by topic when the command name is unknown
search regression

* Look for user written commands
findit outreg2

Help pages open in the Viewer. Each begins with the syntax, and worked examples appear at the end. Reading the examples first is often the quickest way to learn a command.

Working folder

The working folder

Stata reads and writes files in its working folder unless told otherwise. Setting it at the start of each session prevents most file not found errors.

* List the files in the folder

Replace the example paths with a folder on your computer, place the BDHS file in it, and confirm with pwd and ls.

Do files

Do files

A do file is a plain text file of commands that Stata runs in order. Typing in the Command window suits exploration, whereas a do file is the right place for work that must be repeated, checked or shared.

  • Open the editor from the toolbar, from the menu, or by typing doedit.
  • Save the file with the extension .do.
  • Run it with the Execute (do) button, or press Ctrl+D on Windows and Cmd+Shift+D on a Mac. If lines are selected, only those lines run.
Do files

Comments

StyleUse
* textA comment on its own line, with the asterisk at the start.
// textA comment at the end of a command line, with a space before the slashes.
/* text */A comment that may run over several lines.
///Continues a long command onto the next line.

Comments explain why a step is taken. They are ignored when the do file runs.

Opening a dataset

Raising the variable limit with set maxvar

Stata limits the number of variables that a dataset may hold. In Stata/SE and Stata/MP the default limit is 5,000. The BDHS file has 5,425 variables, so Stata refuses to open it until the limit is raised.

clear all
set maxvar 10000
  • clear all empties the memory. The limit can be changed only while no data are loaded.
  • set maxvar 10000 raises the limit to 10,000 variables for the current session. Add , permanently to keep the setting for later sessions.
  • query memory shows the limit that is currently in force.
  • Stata/SE allows up to 32,767 variables, and Stata/MP allows more. Stata/BE is fixed at 2,048 variables and cannot be changed.

Stata/BE users. Load only the variables you need, by naming them before the file. This works in every edition.

use v001 v002 v003 v005 v012 v024 v025 v106 v190 v201 using "BDIR81FL.DTA", clear
Opening a dataset

Opening the BDHS dataset

clear all
set maxvar 10000
use "BDIR81FL.DTA", clear
describe, short
  • The first two lines raise the variable limit, as explained on the previous slide.
  • use loads a Stata dataset into memory. The clear option discards any dataset already there.
  • describe, short reports only the number of observations and variables, along with the size of the data.

Avoid a plain describe on this file. With 5,425 variables, describe fills the Results window with a very long list. Use the short option first.

Opening a dataset

Finding variables in a large dataset

lookfor education
lookfor wealth
codebook v106
  • lookfor searches variable names and labels for a word, which is the standard way to find a variable in a DHS file.
  • codebook shows the label, the type, and the coded values of a variable, with their meanings.
Opening a dataset

Looking at observations

list v001 v002 v003 v012 v025 in 1/5
browse v001 v002 v003 v012 v025
count
count if v025 == 2
  • list prints values in the Results window. in 1/5 limits the output to the first five rows.
  • browse opens the Data Browser, here limited to the named variables.
  • count reports the number of observations, optionally those meeting a condition.
Opening a dataset

First summaries

summarize v012 v201
tabulate v025
tabulate v106
tabulate v025 v106, row
  • summarize reports the number of observations, mean, standard deviation, minimum and maximum of numeric variables.
  • tabulate gives frequencies of a categorical variable. With two variables it gives a cross table, and row adds row percentages.

Read the output together with the codebook, so that each code is matched to its meaning.

Structure

Two kinds of variable

KindHoldsExamples in the BDHS file
NumericNumbers, including coded categoriesv012 age, v201 children ever born, v025 residence (coded 1 and 2)
StringText of any kindNames, free text answers, identifiers such as caseid

Arithmetic and most statistical commands need numeric variables. A categorical variable is normally stored as a numeric code, with a value label that supplies the words.

Working with the BDHS file

Keeping the variables you need

The BDHS file has 5,425 variables, but an analysis normally needs only a few. The command keep retains the variables named and removes all others from memory.

keep v001 v002 v003 v005 v012 v024 v025 v106 v190 v201
describe

The file on disk is not changed until a dataset is saved over it. Working with a small subset makes every later command faster and the output easier to read.

Working with the BDHS file

Variable labels and value labels

A variable label describes the variable. A value label attaches words to numeric codes, so that the code 2 can display as rural.

describe v025
label list V025
tabulate v025
tabulate v025, nolabel
  • The name of the value label is shown in the describe output. In this file the labels are named in capitals, such as V025.
  • label list prints the codes and their words.
  • The nolabel option shows the underlying numeric codes instead of the words.
Working with the BDHS file

Missing values

  • A missing numeric value is shown as a period, .. A missing string is an empty text.
  • Stata also has extended missing codes, .a to .z, that record why a value is missing.
  • In comparisons, a missing numeric value counts as larger than any number, so a condition such as v201 > 5 is true for missing values.
  • Use the function missing() to test for missing values safely.
count if missing(v201)
count if v201 > 5 & !missing(v201)

Survey files often store a special code, such as 99 or 998, for answers that are not known. Such a code is an ordinary number to Stata until it is converted to missing, which is covered in Session 2.

Saving data

Saving and reopening a dataset

save "bdhs_small.dta", replace
use "bdhs_small.dta", clear
  • save writes the dataset in memory to a .dta file. Without replace, Stata refuses to overwrite an existing file of the same name.
  • Saving under a new name keeps the original file safe. Never save over the raw data file.
  • A colleague using an older version of Stata may need saveold "bdhs_small.dta", replace, which writes a copy that older versions can read.

Importing

Importing an Excel file

import excel "bdhs_sample.xlsx", sheet("Women") firstrow clear
describe
list in 1/5
  • sheet() names the worksheet to read. Without it, Stata reads the first sheet.
  • firstrow tells Stata that the first row holds the variable names.
  • clear discards any dataset already in memory.
  • To read only part of a sheet, add cellrange(A1:H301).
Importing

Importing a CSV file

import delimited "bdhs_sample.csv", clear
describe
list in 1/5
  • import delimited reads text files whose values are separated by commas, tabs or another character.
  • Stata uses the first row as variable names when it looks like a header.
  • Add delimiter(";") if the separator is not a comma.
